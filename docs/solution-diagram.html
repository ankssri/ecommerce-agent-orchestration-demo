The orchestrator uses the LLM for intent understanding and reply wording, while policy checks, MCP lookups, approval gating, idempotency, retries, and auditability remain deterministic.

Front Door Customer enters through the web UI, which calls the Flask API and then the orchestrator.
Hybrid Intelligence BytePlus LLM handles understanding and wording; deterministic policy logic controls workflow execution.
MCP Isolation Customer, order, product, shipping, payment, and policy are modeled as separate systems behind MCPs.
Safety Controls Human approval, retries, idempotency, audit logging, and workflow resume protect irreversible actions.
